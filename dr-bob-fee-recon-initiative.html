R1

CD vs. Settlement Statement

Government Recording Fees on the Final CD must match the Final Settlement Statement. Mismatch = inaccurate fee disclosure to borrower.

R2

FSS vs. Recorded Warranty Deed

FSS recording fee must match the fee stamp on the Recorded Warranty Deed. Mismatch = borrower overcharge. Refund legally required.

R3

FSS vs. Recorded DOT / Security Instrument

FSS recording fee must match the fee stamp on the Recorded Deed of Trust. Mismatch = borrower overcharge. Refund legally required.

🔴 The Big 3 Rabbit Hole — Minutes of Friction Before a Single Decision

Document Retrieval

  • Navigate 3 separate Byte tabs (DOCS, PROP, POST CLSNG)
  • Identify which version is the recorded one — multiples often exist
  • Hunt Byte tabs for the right versions across all 3 tabs

Manual Comparison

  • Open each document, locate fee amounts — location varies by county recorder
  • Compare all values line by line across The Big 3 docs
  • Sign checklist — that's the entire audit trail

Exception Handling

  • Missing docs → navigate Parties screen, find Settlement Agent, email request, wait
  • Fee mismatch → determine refund requirement, notify Title Company

The Scale Problem

All of this happens per loan. At CMG's post-close audit volume, this is an enormous ongoing time cost with compounding human error risk — before a single reconciliation decision is made.

⚠️ Compliance Risk — Borrower Overcharge Exposure

Under RESPA, if recording fees charged to the borrower don't match what was disclosed on the CD and FSS, a refund to the borrower is legally required — made by the Title Company via the Settlement Agent.

Why Risk Compounds at Scale

  • Volume: Same multi-step process per loan — error rate multiplies with count
  • Fatigue: Stare-and-compare across The Big 3 docs per loan degrades accuracy over a shift

What Dr. BoB Delivers

  • Fee location variability handled: Fee stamps appear in different locations by county — Dr. BoB scans all known positions
  • Systematic detection: Every loan, every time, without fatigue

🔑 The Stacking Order as Schema

Traditional OCR must figure out what it's looking at before extracting anything — error-prone and unreliable at scale. Dr. BoB doesn't have that problem.

Because BoB generates the PDF in a known, fixed stacking order, Dr. BoB knows before it opens the file:

  • Doc 1 = Final CD → extract Government Recording Fees from Section H
  • Doc 4 = Final Settlement Statement → extract Government Recording Fees section
  • Doc 5 = Recorded Warranty Deed → scan top-right page 1, then last page, then attached pages
  • Doc 6 = Recorded DOT → scan right corner or attached page

Structured, deterministic extraction — not guesswork. This is why Phase 0 (the BytePro stacking order config) is the critical gate. Without a fixed bundle structure, Dr. BoB cannot operate reliably.

📖 Source of Truth — CMG Recording Fee Reconciliation Guide

The Big 3 document stacking order and validation rules are derived directly from CMG's internal Recording Fee Reconciliation Guide — the same document that defines today's manual process.

The guide specifies:

  • Which documents are required for a recording fee reconciliation
  • Where they live in Byte Stored Documents (which tab)
  • Where fee amounts appear on each doc (first page top-right, last page, or attached)
  • Comparison logic — FSS fees must match fee stamps on recorded instruments
  • Remediation path — mismatch requires refund via Settlement Agent / Title Company

Dr. BoB automates exactly this process — same documents, same sequence, same logic. Without human eyes reading every page.

R1 CD vs. Final Settlement Statement

What Dr. BoB Extracts

  • Doc 1 — Final CD: Government Recording Fees section (Section H)
  • Doc 4 — Final Settlement Statement: Government Recording Fees section

Comparison

All line item fee amounts must match between the two documents.

Why It Matters

The CD discloses what the borrower was told they'd be charged. The FSS shows what was actually charged at closing. Any discrepancy = inaccurate fee disclosure.

Flag Message

"Government Recording Fees on Final CD do not match Final Settlement Statement. CD: {$X}, FSS: {$Y}. Disclosure discrepancy — review required."

R2 FSS vs. Recorded Warranty Deed

What Dr. BoB Extracts

  • Doc 4 — FSS: Government Recording Fees section
  • Doc 5 — Recorded Warranty Deed: Fee stamp scanned in order: (1) top-right of page 1, (2) bottom of last page, (3) separate attached page

Why It Matters

The fee stamp on the recorded instrument is what the county actually charged. If it differs from FSS, the borrower was overcharged — a refund is legally required.

Flag Message

"Warranty Deed fee ({$X}) ≠ FSS fee ({$Y}). Borrower overcharge — notify Settlement Agent and Title Company."

R3 FSS vs. Recorded Deed of Trust

What Dr. BoB Extracts

  • Doc 4 — FSS: Government Recording Fees section
  • Doc 6 — Recorded DOT: Fee stamp scanned: (1) right corner of doc, (2) separate attached page

Why It Matters

Same RESPA compliance requirement as R2 — the DOT recording fee is a separate county charge that must match what was disclosed and charged to the borrower.

Flag Message

"DOT/Security Instrument fee ({$X}) ≠ FSS fee ({$Y}). Borrower overcharge — notify Settlement Agent and Title Company."

R4 Bundle Completeness Check

When It Runs

First check — before any OCR begins. A reconciliation is only valid if all required documents were reviewed.

Why It Matters

If the Recorded Warranty Deed is missing, Dr. BoB cannot confirm the recording fee matches. Result = incomplete, not a pass.

Flag Messages by Missing Doc

  • "Final CD not found. Reconciliation cannot proceed."
  • "Final Settlement Statement not found. Reconciliation cannot proceed."
  • "Recorded Warranty Deed not found. Request from Settlement Agent via Parties screen in Byte."
  • "Recorded DOT not found. Request from Settlement Agent via Parties screen in Byte."
